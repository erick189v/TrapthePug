# 🐾 Trap The Pug

Trap The Pug is a grid-based strategy game inspired by *Trap the Cat* and *Trap the Pig*. After spending time with my own pug, I decided to take a creative twist and build this fun challenge using HTML, CSS, and JavaScript.

In this game, your goal is to **trap the pug** before it escapes the grid. The pug moves automatically, and players must block tiles to corner it.

![Trap The Pug Screenshot](./assets/Screenshot%202025-05-12%20at%2011.08.26 AM.png)

## 🎮 How to Play

- Click on empty tiles to block them.
- The pug will try to escape after each move.
- Block strategically to trap the pug before it reaches the edge!

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)

## 📦 Features

- 11x11 dynamic grid
- Autonomous pug movement
- Game automatically resets after a win or escape
- Minimal UI for a clean, focused gameplay experience

## 💡 Inspiration

This project was inspired by the original *Trap the Cat* game, *Trap the Pig*, and of course—my own pug. It also gave me a chance to explore grid logic and movement algorithms in a fun way.
